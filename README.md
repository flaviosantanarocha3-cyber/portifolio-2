
# 💻 Meu Portfólio Pessoal

Este é o repositório do meu **portfólio pessoal**, desenvolvido para apresentar meus principais projetos, habilidades e informações de contato de forma clara, moderna e totalmente responsiva.

O projeto foi desenvolvido com foco em **performance, responsividade, interatividade e experiência do usuário**, utilizando apenas tecnologias nativas da web — sem frameworks ou bibliotecas externas.

## 🚀 Tecnologias Utilizadas

O projeto foi construído 100% com:

* **HTML5:** Estruturação semântica, organização do conteúdo e acessibilidade.
* **CSS3:** Design system com variáveis (`:root`), Flexbox, Grid, efeitos de iluminação (`radial-gradient`), bordas com transparência e Media Queries para responsividade.
* **JavaScript (Vanilla JS):** Interações dinâmicas, scroll suave, menu mobile, scroll spy, animações de revelação com `IntersectionObserver` e envio do formulário via `fetch`.
* **Formspree:** Serviço de gerenciamento de formulários que permite receber mensagens enviadas pelo formulário de contato diretamente por e-mail, sem a necessidade de desenvolver um backend próprio.

> Todo o código é **auto-contido**: fontes (`Brunson`), ícones (SVG inline) e estilos são locais, sem dependência de CDN.

## 🎨 Identidade Visual

* **Tema escuro profissional** (`Dark Mode`) com `--maisEscuro` como cor base.
* **Iluminação suave ("soft glow")** com `radial-gradient` em opacidades baixas.
* **Bordas finas com transparência** (`1px solid rgba(255,255,255,0.1)`).
* **Componentes flutuantes** (menu mobile, cards, formulário) com `border-radius` generoso (16–24px) e `box-shadow` suaves.
* **Fonte display local:** `Brunson` / `Brunson Rough` (hospedadas em `fontes/`).

## 📱 Funcionalidades Principais

* **Design Responsivo:** Layout adaptado para computadores, tablets e dispositivos móveis.
* **Menu Responsivo:** Navegação mobile em painel lateral com blur e animação de hambúrguer.
* **Animações de Scroll:** Revelação suave das seções com `IntersectionObserver` (com fallback sem JavaScript e respeito a `prefers-reduced-motion`).
* **Scroll Suave:** Navegação entre seções descontando a altura do menu fixo.
* **Scroll Spy:** Link ativo destacado conforme a seção visível.
* **Seção de Portfólio:** Apresentação dos principais projetos desenvolvidos.
* **Formulário de Contato:** Integração com o Formspree via `fetch`, com feedback de sucesso/erro em tempo real.
* **Botão "voltar ao topo"** e **ano dinâmico** no rodapé.
* **Foco em Performance:** Código leve, modular e organizado, sem dependências externas.

## 🎯 Objetivo do Projeto

O objetivo deste projeto é apresentar minha evolução como **Desenvolvedor Front-end**, reunindo projetos práticos e demonstrando conhecimentos em **HTML, CSS, JavaScript, responsividade e animações web**.

O portfólio também funciona como um espaço para apresentar projetos desenvolvidos durante meus estudos e minha preparação para ingressar profissionalmente na área de tecnologia.
